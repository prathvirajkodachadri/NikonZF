FOUR RULES

Four short rules
to remember.

RULE 01

Pick a lens, then a place, then the light — only then the settings.

RULE 02

Set shutter first if people move. Set aperture first if the background matters. Set ISO last.

RULE 03

Keep ISO as low as the light allows. Use the front dial, not Auto, when the scene is mixed.

RULE 04

White balance by eye, not by Auto. Pin Kelvin once and forget it.
